O mesmo, em Python de verdade

O que você espera que o código imprima?
Na primeira vez, o navegador baixa o Python (~20 MB). Leva alguns segundos.
Baixa o matplotlib, cerca de 10 MB a mais.
O código que desenhou esta figura

A última linha devolve a figura como texto; é assim que ela sai do Python e aparece na página.

import matplotlib
matplotlib.use("Agg")          # desenha na memória, não numa janela
import io, base64
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(7)
x = rng.uniform(0, 10, n)      # o n vem do slider acima
y = 0.8 * x + rng.normal(0, 1.2, n)

fig, ax = plt.subplots(figsize=(6.4, 4))
ax.scatter(x, y, c="#7B61FF", s=36, edgecolor="white")
ax.set_xlabel("medida")
ax.set_ylabel("resposta")

buf = io.BytesIO()
fig.savefig(buf, format="png", dpi=120, bbox_inches="tight")
plt.close(fig)
base64.b64encode(buf.getvalue()).decode()
